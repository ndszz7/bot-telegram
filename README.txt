# BOT TELEGRAM TIKTOK HD

## 1. Instale o Node.js
https://nodejs.org/

## 2. Instale Python
https://www.python.org/downloads/

MARQUE:
Add Python to PATH

## 3. Instale yt-dlp

Abra o CMD:

pip install yt-dlp

## 4. Instale ffmpeg
https://www.gyan.dev/ffmpeg/builds/

Baixe:
ffmpeg-release-essentials.zip

Extraia e adicione a pasta BIN no PATH.

Teste:

ffmpeg -version

## 5. Abrir projeto

No CMD:

cd telegram-tiktok-bot

## 6. Instalar dependências

npm install

## 7. Colocar token

Abra index.js

Troque:

const token = 'SEU_TOKEN_AQUI';

pelo token do BotFather.

## 8. Rodar bot

node index.js

## 9. Como usar

Envie um link do TikTok para o bot.
